# Cabusog Fitness

Cabusog Fitness is a PHP and MySQL-based fitness web application designed to help users manage their fitness goals, activities, and programs.

## Features

- User Registration
- User Login
- User Dashboard
- Fitness Programs
- Goal Tracking
- Activity Tracking
- Recommendations
- User Profile
- Logout

## Technologies

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap
- XAMPP

## Local Setup

1. Install XAMPP.
2. Copy the project into `htdocs`.
3. Start Apache and MySQL.
4. Create the `cabusog_fitness` database in phpMyAdmin.
5. Import the database SQL file.
6. Open:

http://localhost/Cabusog_Fitness_1/
